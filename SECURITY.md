# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories. If you
cannot use GitHub, email <security@secpal.app>. A PGP key is available on request.
[Report a vulnerability](https://github.com/SecPal/api/security/advisories/new)

Include the affected version or revision, relevant component, steps to reproduce
and potential impact. Use the private channel for coordinated disclosure.
[Published security advisories](https://github.com/SecPal/api/security/advisories)
